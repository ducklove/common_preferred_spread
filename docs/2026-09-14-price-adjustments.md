# 대교 액면병합 가격 복구

대교는 액면가 500원 주식 2주를 1,000원 주식 1주로 병합했다.
[변경상장 공시](https://stock.mk.co.kr/news/disclosure/template/1134745)의 거래 재개일은
2026-09-10이다. 보통주 40,233,850주, 우선주 9,713,495주가 상장됐다.

## 원인과 수정

- finance-pi의 과거 Naver 가격은 수집 당시 수정주가였다. 이후 병합이 발생해도
  `price_basis=adjusted`라는 이유로 재보정에서 제외됐다.
- 소비 측도 최근 구간만 병합하므로 원천의 과거 가격 수정이 전체 이력에 전달되지 않았다.
- 같은 날짜의 저장 가격과 새 가격 차이가 5%를 넘으면 관련 종목 전체를 재조회한다.
  당일 등락률을 병합비율로 추정하거나 기존 가격에 임의 비율을 곱하지 않는다.
- 전체 재조회에서 기존 날짜가 빠지면 저장을 중단한다. 작은 정정이나 과거 구간만의
  정정은 `python fetch_data.py --refresh-pairs daekyo`로 재조회한다.
- 대교 배당 이력은 이미 병합 후 120원으로 조정돼 있었다. 현재 배당액에 남아 있던
  60원 고정값도 120원으로 맞췄다. 이는 과거 배당의 주식 단위 환산이며 미래 배당 예측이 아니다.

## 데이터 검증

- 2026-08-13 보통주 1,000 → 2,000원, 우선주 598 → 1,196원.
- 2026-09-10 실제 종가 1,874원 / 1,059원, 09-11 1,819원 / 1,036원은 유지.
- 대교 히스토리 5,376 → 5,552일. 원천에서 확인된 거래일을 보완했다.
- 기존의 2006-05-31 한 행은 지방선거 휴장일의 잘못된 가격이므로 제외했다.
  [당시 거래소 휴장 안내 보도](https://www.hankyung.com/article/2006051702091).
- 원천 수정주가로 전체 가격·괴리율을 다시 계산하고, 기존 산식으로 괴리율 지수와
  대교 투자매력도를 재계산했다. 다른 개별 종목의 데이터는 보존했다.
- Python 94개, JavaScript 108개 테스트 통과.

복구 비교 자료와 수집 원천은 로컬 `.cache/action-audit/`에 보관했다.
연관 작업은 finance-pi의 가격 재조회·백업 도구와 holding_value의 바이오스마트 복구이다.
