# 연구 데이터 API v1

`data/research/v1/manifest.json`은 최신 버전을 가리키고,
`snapshots/<sha256>.json`은 원본 UTF-8 바이트의 SHA-256으로 식별하는 불변 자료다.
`python research_api.py`로 생성하며 일일 수집 워크플로우가 함께 커밋한다.
같은 입력을 다시 생성하면 최초 `published_at`을 유지한다. 기존 스냅샷은 삭제하지 않는다.

국내 보통주·우선주 관계, 권리 프로필·개별 검토, 상장 검토와 배당 관측 자료를 제공한다.
현재 종목 관계이며 과거 시점 유효성은 검증 전이다. 배당 관측값은 총수익 시계열이 아니다.
권리 정보의 `reviewed_at`은 시세 갱신일과 다르며 갱신으로 최신 검토를 가장하지 않는다.

finance-pi는 GitHub raw의 같은 경로를 읽어 Pages 배포 시차와 독립적으로 수집한다.
종목 관계를 자체 security_relations와 교차 검증하고 가격 이력·백테스트를 담당한다.
value-invest는 고정 버전의 연구 등록·보고서·관찰을 담당한다. 실행 승인 필드는 항상 false다.
소비자는 해시, 계약 버전, 기준일·게시 시각(14일 이내)을 검사하고 장애 시 신규 연구를 보류한다.
